# Edumerge Node.js

Node.js Assignment project for Edumerge.

## About

TASK: GitHub Profile Analyzer API

## Getting Started

## Tech Stack

- Node.js
- Express.js
- MySQL
- Axios
- GitHub REST API

### Prerequisites
- Node.js
- npm

### Installation

```bash
npm install
```

### Usage

```bash
npm run dev
```

## Features

- Fetch GitHub user profile data
- Store analyzed profiles in MySQL
- Get all analyzed profiles
- Get a single analyzed profile by username
- Handle duplicate profiles using update functionality
